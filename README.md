# চাকরি/নিয়োগ খবর সংগ্রহ ও রিমাইন্ডার সিস্টেম

বিভিন্ন সংবাদপত্র ও সরকারি ওয়েবসাইট থেকে চাকরি/নিয়োগ বিজ্ঞপ্তি প্রতিদিন
স্বয়ংক্রিয়ভাবে সংগ্রহ, আগ্রহী চিহ্নিত করা, আবেদনের শেষ তারিখের আগে
রিমাইন্ডার (Web Push), আর প্রতি শুক্রবার সাপ্তাহিক ব্যক্তিগত রিপোর্ট —
সবকিছু একটা PWA (Cloudflare Pages) দিয়ে।

## ডকুমেন্টেশন

- **[PROJECT_NOTES.md](./PROJECT_NOTES.md)** — প্রজেক্টের আর্কিটেকচার,
  ফাইল কাঠামো, ডাটাবেজের গঠন, মূল সিদ্ধান্তসমূহ, জানা সীমাবদ্ধতা ও
  ভবিষ্যৎ পরিকল্পনা — অর্থাৎ প্রজেক্ট নিয়ে ভাবতে/কাজ করতে যা যা জানা দরকার
- **[SETUP.md](./SETUP.md)** — একবারের জন্য করতে হয় এমন সব সেটআপ ধাপ
  (GitHub Secrets, Cloudflare Pages কনফিগারেশন) — প্রজেক্ট একবার লাইভ
  হয়ে গেলে সাধারণত আর দরকার পড়ে না
